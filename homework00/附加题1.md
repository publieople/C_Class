# 附加题 (Additional Question)

Write a menu-driven program that allows the user to fill an array of 50 integers with random numbers in the range 1…… 999, sort it, and then search it to determine if a given random number was generated. The menu is shown below.

编写一个菜单驱动的程序，允许用户用 1……999 范围内的随机数填充一个包含 50 个整数的数组，对其进行排序，然后搜索它以确定是否生成了给定的随机数。菜单如下所示。

## MENU (菜单)

Select one of the following options:
选择以下选项之一：

**F. Fill array with a random number series**
**F. 用随机数序列填充数组**

**P. Print the array**
**P. 打印数组**

**S. Sort the array**
**S. 对数组进行排序**

**Q. Query the array**
**Q. 查询数组**

**Z. Terminate the program**
**Z. 终止程序**

1. Each time the fill option is executed, it will fill the array with a new random number series.
   每次执行填充选项时，都会用新的随机数序列填充数组。

2. You may use any of sorts discussed in the text.
   您可以使用文中讨论的任何排序方法。

3. If the query locates the number, it will print a message that the number was located and index location where it was found.
   如果查询找到了该数字，它将打印一条消息，说明已找到该数字及其所在的索引位置。

4. If the query does not locate the number, it will print a message that the number was not in the list and then print the value and index location of the largest number less then the target and the smallest value greater than the requested number. Note that the first and last elements will not have both a smaller and larger value.
   如果查询未找到该数字，它将打印一条消息，说明该数字不在列表中，然后打印小于目标值的最大数和大于请求值的最小数的数值及索引位置。注意，第一个和最后一个元素不会同时拥有较小值和较大值。

5. If the array has been sorted, the query will use a binary search. If it is not sorted, it will use the sequential search.
   如果数组已排序，查询将使用二分查找。如果未排序，将使用顺序查找。

## To test the program (测试程序)

1. Fill (F) the array.
   填充 (F) 数组。

2. Print (P) the unsorted array.
   打印 (P) 未排序的数组。

3. Search (Q) the first, last, and a middle element.
   搜索 (Q) 第一个、最后一个和中间的元素。

4. Refill (F) the array.
   重新填充 (F) 数组。

5. Sort (S) the array.
   排序 (S) 数组。

6. Print (P) the sorted array.
   打印 (P) 已排序的数组。

7. Search (Q) the first, last and a middle element.
   搜索 (Q) 第一个、最后一个和中间的元素。

8. Search (Q) for a number that will be found in the list.
   搜索 (Q) 一个将在列表中找到的数字。

9. Search (Q) for a number that will be not found in the list.
   搜索 (Q) 一个不会在列表中找到的数字。
